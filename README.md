# proj5

Static site published with GitHub Pages: https://1clan.github.io/proj5

**lifectl** — a minimalist, local-first life management platform.

- Overview dashboard · Tasks · Habits · Goals · Notes · Focus timer
- Vibrant modern palette with a Linux/terminal taste (JetBrains Mono + Space Grotesk)
- Everything persists in `localStorage` (`lifectl.v1`) — no account, no server
- Keyboard: `1`–`6` navigate, `/` quick-add, `Space` start/pause the timer
- Export / reset your data from the sidebar
